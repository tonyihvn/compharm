ISSUE #4: Column Visibility Menu Crash
================================================================================
Status: ✅ FIXED
Severity: Critical (Crash)
File: python-pharmacy-app/ui/widgets/enhanced_client_list.py (Lines 31-37)

Problem:
  - Right-clicking column header for visibility settings crashed app
  - Error: AttributeError: 'ColumnVisibilityMenu' has no attribute 'insertWidget'
  - insertWidget() is a QMenuBar method, not available on QMenu
  - Users couldn't manage column visibility

Solution:
  - Replaced insertWidget() with setDefaultWidget()
  - setDefaultWidget() is the correct PyQt6 method for QMenu
  - Menu checkboxes now display properly without crashes

Code Change:
  Before (CRASH):
    action = self.addAction("")
    action.setCheckable(False)
    self.insertWidget(self.actions().index(action), checkbox)  # ❌ CRASH
  
  After (FIXED):
    action = self.addAction("")
    action.setCheckable(False)
    action.setDefaultWidget(checkbox)  # ✅ Works

Why This Works:
  - QMenu.addAction() creates an action
  - QAction.setDefaultWidget() properly embeds widget in menu
  - QMenu doesn't have insertWidget() method
  - This is the standard PyQt6 pattern

Verification:
  ✓ insertWidget() removed
  ✓ setDefaultWidget() added and used correctly
  ✓ Code compiles without errors
  ✓ File syntax verified
